# Daryeel Item Care

APP NAME

Daryeel

Tagline:

"Your belongings, always connected."

Daryeel is a personal belongings management app.

Users can register their personal belongings such as:

Laptops

Phones

Cameras

Tablets

Cars

TVs

Refrigerators

Air conditioners

Important documents

Other personal items

Each item will eventually have a unique QR code that can be attached physically to the item.

When somebody scans the QR code using their normal phone camera, they will see a public page containing:

Item Name

Owner Name

Contact Number

The public page must have a Contact Owner button.
