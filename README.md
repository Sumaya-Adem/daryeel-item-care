# Daryeel Item Care

Design a complete, modern, professional UI/UX for a mobile-first application called Daryeel.

IMPORTANT:
This stage is for UI/UX DESIGN ONLY.

Do NOT build the backend.
Do NOT create the database.
Do NOT implement authentication logic.
Do NOT create APIs.
Do NOT implement QR generation logic yet.

Focus only on creating the visual design, screen structure, navigation, components, colors, typography, spacing, and user experience.

APP NAME

Daryeel

Tagline:

"Your belongings, always connected."

Daryeel is a personal belongings management app.

Users can register their personal belongings such as:

Laptops

Phones

Cameras

Tablets

Cars

TVs

Refrigerators

Air conditioners

Important documents

Other personal items

Each item will eventually have a unique QR code that can be attached physically to the item.

When somebody scans the QR code using their normal phone camera, they will see a public page containing:

Item Name

Owner Name

Contact Number

The public page must have a Contact Owner button.

DESIGN STYLE

Create a design that feels:

Modern

Clean

Minimal

Professional

Friendly

Trustworthy

Simple

Premium but not expensive-looking

Easy for first-time users

The application should feel like a real startup product.

Do NOT make it look like:

A complicated ERP

A warehouse management system

A marketplace

Daryeel should feel like a personal digital care system for the things you own.
